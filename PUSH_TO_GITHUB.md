# Hospital Appointments Management System

This repository contains a Java-based console application for managing hospital appointments, users, and reporting. 

## Project Structure
- Java source files: Main.java, HospitalSystem.java, Admin.java, Doctor.java, Patient.java, User.java, Appointment.java, FileManager.java
- Data files: users.txt, doctors.txt, patients.txt, appointments.txt
- Documentation: README.md, LICENSE
- CI/CD: .github/workflows/java-ci.yml
- Ignore rules: .gitignore

## How to Push to GitHub
1. Initialize a git repository if you haven't:
   ```bash
   git init
   ```
2. Add all files:
   ```bash
   git add .
   ```
3. Commit your changes:
   ```bash
   git commit -m "Initial commit"
   ```
4. Add your remote repository:
   ```bash
   git remote add origin https://github.com/your-username/your-repo.git
   ```
5. Push to GitHub:
   ```bash
   git push -u origin main
   ```

Replace `your-username` and `your-repo` with your actual GitHub username and repository name.
